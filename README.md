# 🦎 めっちゃカメレオン

同じWiFi（LAN）内のスマホ・PCのブラウザで遊べる、「カメレオン」風の正体隠しワードゲームです。

## 起動

```sh
npm start        # または node server.js（依存パッケージなし / Node.js 18+）
```

起動するとターミナルに `http://192.168.x.x:3000` のようなアドレスが表示されます。
同じWiFiにつないだ端末のブラウザでそのアドレスを開けば参加できます（3〜12人）。
ポートを変える場合は `PORT=8080 npm start`。

## 遊び方

1. 16個のワードが並んだお題カードから、秘密のワードが1つ決まります。
2. 1人だけ「カメレオン」になり、カメレオンには秘密のワードが知らされません。
3. 順番にヒントを1つずつ出します。
4. 話し合って、カメレオンだと思う人に投票します（同票なら決選投票を1回）。
5. カメレオンが見破られても、秘密のワードを当てれば逃げ切りです。

得点: 逃げ切り → カメレオン+2 / 見破られたがワード正解 → カメレオン+1 / 捕まえた → 他の全員+2
