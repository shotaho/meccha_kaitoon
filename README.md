# 🦎 めっちゃカイトオン

真っ白な体に絵を描いて背景に溶け込む「お絵かきかくれんぼ」を、
**PC・スマホのブラウザ**で対戦できるようにしたものです。

## 遊ぶ方法は2つ

### A. GitHub Pages 版（インストール不要・おすすめ）

**https://shotaho.github.io/meccha_kaitoon/** を開くだけ。

1. ホストが「新しい部屋を作る」→ 4桁の部屋番号と招待URLが出る
2. 友だちは招待URLを開くか、部屋番号を入力して「入る」（ニックネームは空でもOK）
3. ホストがルールを決めて「ゲームスタート！」（1人ならCPUと対戦）

- ホストのブラウザがゲームの進行役になり、他の人は WebRTC（P2P）でホストに直接つながります。
  つなぐときだけ PeerJS の無料シグナリングサーバーを使うので、インターネット接続が必要です。
- 直接つながれないとき（ルーターや端末の組み合わせによる）にそなえて、次の順にためします。
  1. TURN サーバー（peerjs・openrelay）を通して WebRTC でつなぐ
  2. それでもだめなら（8秒たってもつながらないとき）、公開のメッセージサーバー（MQTT：broker.emqx.io / broker.hivemq.com）を通して中継する。
     ホストは部屋を作ると、直接と中継の両方で待ち受けます。PeerJS のサーバーにつながらないときも、中継だけで部屋をひらきます
- 中継は公開サーバーを通るので、部屋の中のやりとり（位置・ペイント）は第三者にも見える可能性があります。
- テスト用：`?relay=only` で最初から中継、`?relayurl=wss://…/mqtt` で中継サーバーを変えられます。
  同じWiFiでなくても遊べます（回線によってはつながらないことがあります）。
- **ホストは画面を閉じたり、別のタブ・アプリに切り替えたままにしないでください**（部屋がなくなる／動きが止まる）。
  できればPCでホストしてください。
- 自前の PeerJS サーバーを使う場合は `?peerserver=https://example.com:9000/` をURLに付けます。

#### デプロイ
`.github/workflows/pages.yml` が `public/` を GitHub Pages に公開します（push で自動実行）。
初回だけ、リポジトリの **Settings → Pages → Build and deployment → Source** を **「GitHub Actions」** にしてください。

### B. LAN サーバー版（インターネットなしでも遊べる）

```sh
npm start        # または node server.js
```

- 必要なのは Node.js 18 以上だけ（npm install 不要。three.js・PeerJS・MQTT.js は `public/vendor` に同梱）
- 起動するとターミナルに `http://192.168.x.x:3000` のようなアドレスが出るので、
  同じWiFiにつないだ端末のブラウザでそのアドレスを開けば参加できます（1〜16人。1人ならCPUと対戦）
- ポートを変える場合は `PORT=8080 npm start`
- つながらない場合は、サーバーPCのファイアウォールでポート 3000 の受信を許可してください

## 遊び方

1. **準備タイム**：隠れる側は部屋の中で場所・ポーズ・向きを決め、真っ白な体にペイントして背景に溶け込む。鬼は待機（画面が真っ暗）。
2. **捜索タイム**：隠れる側も見つかるまでは動いたりペイントで塗り直したりできる（動くと目立つので注意）。鬼は歩き回って、あやしい所にペイント弾を撃つ。当たれば発見、外すと残り時間が減る。
3. **答え合わせ**：全員の隠れ場所が光って表示され、自由にステージを見て回れる。

得点：逃げ切った隠れる側 +3点 ／ 鬼は1人見つけるごとに +1点

### アイテムモード（ルールせっていの「アイテム：あり」）
- ステージのあちこちに **たからばこ** が6こかくしてある。近くで **F**（スマホは🎁/🚪ボタン）であける（かくれる側はじゅんび中から、おにはさがす時間から）。近くに行くと「F キーでたからばこをあける」と出る。アイテムは1つずつしか持てない
- **おに**：🔫ショットガン（3はつ。ちらばるたまで当てやすい）か、📣くちぶえブザー（**G** でつかうと、かくれている全員が数秒くちぶえをふく。音と♪マークで場所がばれる）
- **かくれる側**：🏏バット（3回ふれる）。おにの近くで **G**。たたかれたおには2秒ふらふらで動けない。おにの体力は2で、**2回たたくとおにがたおれる。おにが全員たおれたら、かくれる側の勝ち**（たおした人に +2点）
- CPU のおにも、たからばこをあけてアイテムを使い、くちぶえが聞こえたほうへ向かう

### ステージ
- **おうち** … リビング・キッチン・倉庫っぽい部屋
- **マック** … 赤と黄色の店内、キッチン、ドライブスルー、駐車場
- **マイクラ** … ブロックでできた地形・木・池・小屋
- **うみのなか** … 海底の砂・岩のがけとアーチ・しずんだ船・サンゴのかべ・海そうの森・宝箱
- **くるまのなか** … 小さくなって車の中へ。大きな座席・ダッシュボード・ドア・おもちゃばこ（うしろの座席にのぼれる）
- **おかしのまち** … ジンジャーブレッドの家・ケーキのとう・チョコのかべ・ドーナツ・キャンディの木・グミ・アイス屋さん
- **まち** … 十字路と横断歩道・ビル・コンビニ（うらから屋根にのぼれる）・マンション・バスてい・こうえん（すべりだい・ブランコ・すなば）
- **うちゅう** … 月の地面・月面きち・ロケット・ローバー・うかぶ宇宙ステーションと人工衛星・いんせき。おにもうちゅうふくを着て、重力なしでどこへでもとべる（WASD：みているほうへ、スペース/E：うえ、Q：した）
- **むじんとう** … ヤシの木・竹とわらの小屋（にもつとたるから屋根にのぼれる）・ジャンプでのぼれるがけ・こわれたボート・いかだ・たき火・たからばこ・すなにかいた SOS。西にはジャングルのもり（大きな木・しげみ・たおれた木・いけ・シダ）、南東のあさせにはかいぞくせんのちんぼつせん（中に入れる・にもつから甲板にのぼれる）
- **さどがしま** … たらいぶね・さんばし・佐渡金山のトンネルとトロッコ・歩いてのぼれるたなだ（はさがけ・かかし）・のうぶたいとおにだいこ・木の家・おけさがきの木・トキ
- **100えんショップ** … 商品がならぶたな・レジ・ワゴン・かごおき。プレイヤーとおなじ形のお客さんがいて、まぎれてかくれられる（お客さんを撃つと「はずれ」）
- **けいむしょ** … てつごうしのろうや10へや（2だんベッド・トイレ・たな）・しょくどう・かんしゅのつくえ・シャワー室・ジム・ロッカー。**ろうやのとびらは F キー（スマホは🚪ボタン）で開け閉めできる**（じゅんび中はかくれる側、さがす時間はおに。CPU のおにも開ける）。こうしのすきまから中が見えて、撃てる

### CPU
- **CPU の隠れる側**：ステージの隠れ場所に入り、その場所の正面から見た背景を体に写し取って擬態します（よわいほど塗りムラが多い）。正面以外の角度から見ると見破れます。
- **CPU の鬼**：部屋を歩き回り、視界に入った人が背景からどれだけ浮いて見えるかで発見します（上手に塗るほど見つかりにくい）。部屋のホストのブラウザで動きます。
- **なりすまし**（100えんショップ）：お客さんとおなじ色の服・顔・かみにぬって、ふつうのポーズ（たつ／しゃがむ）で床に立っていると、CPU の鬼は「ただのお客さん」と思って見のがしやすくなります（つよいほど見やぶりやすく、すぐ近くだと少しばれやすい）。
- 1人＋CPUでも、みんな＋CPUでも遊べます。
- トップの **「CPUとすぐ遊ぶ」** なら、部屋を作らず（通信なし）にCPU戦ができます。前回のステージ・CPUの人数と強さを覚えています。
- ホストはラウンドごとに **「おにになる」「かくれる」** を選んで始めます（ほかの人の役はランダム）。友だちと遊ぶときは **「おまかせ」** で全員ランダムにもできます。人間が1人でCPUがいなければ、自動で3人入ります。
- 隠れる側がCPUだけのラウンドは、準備タイムを待たずに3秒で捜索が始まります。

### モード・設定（ホストが変更）
- ステージ、CPU の人数（0〜7）と強さ（よわい／ふつう／つよい）
- **ノーマル** / **増え鬼**（見つかった人が鬼になって一緒に探す）
- 鬼の人数、準備タイム、捜索タイム、はずれペナルティ

## 構成

- `public/js/room.js` … 部屋のゲーム進行（フェーズ・判定・ペイント履歴）。LAN サーバーでもホストのブラウザでも同じコードが動く
- `public/js/net.js` … 通信（LAN版は WebSocket、GitHub Pages 版は PeerJS による WebRTC＋TURN、つながらないときは MQTT で中継）
- `server.js` … LAN 版の HTTP + WebSocket サーバー（依存なしの自前実装）
- `public/js/maps.js` … ステージの共通データ（出現位置・CPU の隠れ場所・ブロック地形の生成）
- `public/js/world.js` … ステージの組み立て（家具・当たり判定）
- `public/js/blocktex.js` … ブロックの世界のドット絵テクスチャ
- `public/js/camo.js` … CPU の擬態ペイント（背景を体に投影）
- `public/js/cpu.js` … CPU 鬼の動きと発見判定
- `public/js/textures.js` … ステージの模様を Canvas で生成（全員同じになるようシード固定）
- `public/js/character.js` … キャラクター、ポーズ、体へのペイント（各パーツの Canvas テクスチャに直接描画）
- `public/js/main.js` … 画面・操作・通信

ペイントは画像ではなく「筆の軌跡（パーツ番号・UV座標・色・太さ）」を送るので軽く、ほぼリアルタイムで全員の画面に反映されます。
